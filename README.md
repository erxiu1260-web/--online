# 云端五子棋

两人实时五子棋网页应用。第一个进入房间的人执黑，第二个人执白；额外进入者可观战。

## 本机启动

在本目录运行：

```powershell
npm start
```

然后访问 [http://localhost:3000](http://localhost:3000)。点击“复制邀请链接”，把链接发给朋友即可加入同一房间。

## 局域网联机

确保朋友和你在同一 Wi-Fi/局域网；将链接里的 `localhost:3000` 替换为你电脑的局域网 IP（可在终端运行 `ipconfig` 查看），例如：

```text
http://192.168.1.20:3000/?room=ABC123
```

如果 Windows 提示防火墙访问，请允许 Node.js 使用专用网络。

## 公网线上联机

将整个文件夹上传至任何支持 Node.js 的托管平台（例如 Render、Railway 或自己的云服务器），设置启动命令为 `npm start`。平台分配的 HTTPS 地址就是可直接分享给朋友的在线地址；应用会自动为每个新链接创建独立房间。

部署平台需要提供 `PORT` 环境变量；程序已自动读取它。
